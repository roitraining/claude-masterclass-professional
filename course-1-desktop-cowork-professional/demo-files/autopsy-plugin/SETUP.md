# Setup: expense-digest

## Install

1. Install Python 3.11 or later and make sure `python` runs from a terminal.
2. Add the plugin:
   - In Claude Code: `claude --plugin-dir ./expense-digest`
   - In Cowork: Customize, Plugins, Add, Upload plugin, and choose a zip of the folder.

## Use

Ask Claude for an expense digest, or run `/expense-digest:digest`.

## Troubleshooting

If nothing happens, restart Claude and try again.
