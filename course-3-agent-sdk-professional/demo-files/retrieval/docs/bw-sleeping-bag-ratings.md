# Sleeping Bag Temperature Ratings

Status: current.

Each Trailhead Sleeping Bag lists a comfort rating and a limit rating. The comfort rating is the lowest temperature at which a typical sleeper stays comfortable. The limit rating is the lowest temperature at which a typical sleeper stays safe for one night, curled up and cold.

Pick a bag whose comfort rating is at or below the coldest night you expect. Use a sleeping pad: the ground removes more heat than the air. Store the bag uncompressed in a large cotton sack. Sleeping bags carry a 2-year warranty.
