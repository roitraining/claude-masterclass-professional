# Summit Stove Safety

Status: current.

Use the Summit Stove outdoors or in a well-ventilated vestibule with the door open. Never use it inside a closed tent. Keep fuel canisters away from open flame and out of direct sun.

Check the canister seal and the hose for cracks before each trip. Let the stove cool for ten minutes before packing it. Stoves carry a 1-year warranty; see the Warranty Guide.
