# Tent Care and Storage

Status: current.

Dry the tent fully before storing it. Pack it loosely in the storage bag, not the compression sack, so the coating does not crack. Clean with lukewarm water and a soft sponge. Never use detergent or a washing machine.

Store the tent in a cool, dry place away from sunlight. Re-seal the seams once every two years or when water begins to bead poorly. Use a footprint under the tent floor to reduce abrasion.
