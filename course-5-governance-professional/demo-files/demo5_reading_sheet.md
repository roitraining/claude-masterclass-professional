# Demo 5 Sample: Read an Adoption Dashboard

All numbers are synthetic. The two CSV files are `demo5_adoption_dashboard_monthly.csv` and `demo5_adoption_dashboard_by_department.csv`.

## The headline on the leadership dashboard

> **AI adoption: 78 percent of licensed seats active weekly, up from 52 percent in March.**

The CEO is pleased. The question for the class is what the headline does not show.

## Step 1: Read the trend

Open the monthly file. Watch two columns: `active_percent` and `prompts_per_active_user`.

## Step 2: Cut by department

Open the department file. Compare `active_percent`, `total_prompts_aug`, `intake_requests_submitted`, `exceptions_past_expiry`, and the two Tier 3 columns.

## Step 3: Sort each metric into a kind

| Metric | Reports activity, value, or risk? | Would it change a decision? |
|---|---|---|
| Weekly active percent | | |
| Total prompts | | |
| Prompts per active user | | |
| Intake requests submitted | | |
| Exceptions past expiry | | |
| Tier 3 uses with evidence, out of Tier 3 uses in the inventory | | |

## Step 4: Name the problems the headline hides

Write at least three. For each give the number that shows it, who owns the follow-up, and a metric that would have exposed it.

## Step 5: Set the response

Write one action per problem, with an owner and a date.

## Caution

An activity metric tells you people logged in. It does not tell you work improved, and it does not tell you the use is safe. Pair every activity metric with a value metric or a risk metric.
