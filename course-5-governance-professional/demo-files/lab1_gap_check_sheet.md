# Lab 1 Gap-Check Sheet

Apply every test to your draft, then apply it again to the inherited text you kept. A gap is a place where an assessor would say "this cannot be enforced, followed or evidenced."

For each row, mark Found (the gap existed in your starting text), Fixed (your draft now passes), or Open.

| ID | Test | Fails when | Passes when | Found | Fixed |
|---|---|---|---|---|---|
| G1 | Name the approver for every approval in the policy. | The text says "management", "the business" or "IT". | A named role, and a deputy when that role is away. | | |
| G2 | Find every exception path. Does each end? | An exception has no expiry date, no record, or no review. | Each exception has an approver, a written reason, an expiry date, and a place in the register. | | |
| G3 | Pick each rule. Could anyone check it? | A rule needs knowledge nobody can have, or proof nobody can collect. | Each rule can be checked by a control or a record, or is written as a duty a person can meet. | | |
| G4 | Read the approved tool list. Is every tool owned? | An owner is blank, or is a team and not a role. | Each tool has an accountable role and a review date. | | |
| G5 | Find the consequence for breaking the policy. | The text says "appropriate action" or nothing. | Consequences are listed by severity, with who decides. | | |
| G6 | Ask who is covered and where. | Contractors, personal devices, phones, or vendor-embedded AI are outside scope. | Scope covers employees, contractors, personal devices used for work, and AI features inside approved vendor tools. | | |
| G7 | Find every data term. Is it defined? | "Sensitive" or similar is used and not tied to Brightwater's data classes. | Rules use the four data classes and say what each allows. | | |
| G8 | Find the review date. | "Periodically" or "as needed". | A fixed interval, a named owner, and a trigger for an early review. | | |
| G9 | Ask: if I want a new tool tomorrow, what do I do? | No request path, or "promptly". | A form, a named decider by tier, and a decision time that matches the tier scale. | | |
| G10 | Find who approves and who audits. Same role? | A single role approves, operates and audits. | Approval and audit are separate roles. | | |
| G11 | Find any use that affects a person. | The text allows it without safeguards. | A person decides, a record is kept, Tier 3 review applies, and counsel and employee representatives are consulted where relevant. | | |
| G12 | Ask: I made a mistake. Who do I tell? | No reporting path. | A named channel and role, a response time, and a statement about how good-faith reports are treated. | | |
