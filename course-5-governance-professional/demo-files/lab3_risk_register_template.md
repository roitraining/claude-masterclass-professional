# Lab 3 Template: Risk Register

Complete one block per use. Keep each answer short and specific.

| Field | Guidance |
|---|---|
| ID | From the portfolio |
| Status flag | None, Not permitted as practiced, Shadow, or Changed |
| Owner | A named current role. Not a team, not blank, not someone who has left. |
| Tier | 1, 2 or 3, with the deciding fact in a clause |
| Main risk | One sentence: what could go wrong and to whom |
| Control | The specific control that reduces the risk. A capability or a process. State its limit. |
| Evidence | An ID from the evidence menu that shows the control worked |
| Next review | A date, and the event that would trigger an earlier review |
